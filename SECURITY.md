# Security Policy

## Supported Versions

The following versions of Kafka SQL Explorer are currently being supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 0.0.1   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of Kafka SQL Explorer seriously. If you believe you have found a security vulnerability, please report it to us as described below.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them via email to [security@example.com].

### What to include in your report

Please include as much information as possible to help us reproduce and understand the vulnerability. Useful information includes:

- The version of Kafka SQL Explorer you are using.
- A description of the vulnerability.
- Steps to reproduce the vulnerability.
- Any potential impact of the vulnerability.

### What happens next

After you submit your report, we will:

- Acknowledge receipt of your report within 48 hours.
- Investigate the vulnerability and determine its severity.
- Work on a fix and release it in a timely manner.
- Keep you informed of our progress.

Thank you for helping us keep Kafka SQL Explorer secure!
