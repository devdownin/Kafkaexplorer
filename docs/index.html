Core Innovation

Query Design at the speed of a click.

Stop manual typing of deep JSON paths. Our Query Assistant analyzes your live stream and lets you build complex Flink SQL by simply clicking on message fields.

  • check_circle Interactive Selection: Click any key to add to SELECT.
  • check_circle Smart Filters: Click values to populate WHERE clauses instantly.
  • check_circle Auto-Inference: Detecting JSON and XML structures for perfect DDL generation.
query_assistant.sql
// Select fields by clicking preview
SELECT order_id,
JSON_VALUE(raw_value, '$.customer.name') AS customer,
amount
FROM "demo.orders.received"
WHERE amount > 500;

Get Started in Seconds

1

Launch Infrastructure

Spin up Kafka 4.3 (KRaft, no Zookeeper) via Docker Compose.

docker compose -f docker-compose.yml -f compose/schema-registry.yml up -d
2

Run the Explorer

Launch the Spring Boot application locally with a single command.

./mvnw spring-boot:run
3

Explore & Query

Open http://localhost:8080 and start mastering your streams.
